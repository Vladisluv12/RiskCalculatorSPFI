# tests/iolib

Тесты ввода-вывода портфелей и отчётов.

`test_portfolio_io.py` проверяет roundtrip портфелей через `iolib.portfolio_io`: сохранение и обратная загрузка должны давать эквивалентный объект для всех поддерживаемых форматов (JSON, YAML, CSV, Excel). Отдельно тестируется поведение при импорте файлов с битыми строками (валидные строки подгружаются, невалидные пропускаются), экспорт IRS в bytes, JSON-roundtrip IRS-контракта и смешанный портфель из forward, swap и IRS.

`test_serializers.py` тестирует низкоуровневые сериализаторы по форматам. Для каждого формата (JSON, YAML, CSV, Excel) проверяются roundtrip, расширение файла и MIME-тип. CSV и Excel дополнительно тестируются как на списке словарей, так и на DataFrame.

`test_report_builder.py` проверяет конструктор PDF-отчётов: добавление и удаление секций, корректный возврат байтов PDF при сборке, поведение при пустом наборе данных.

`test_results_exporter.py` проверяет экспорт результатов расчёта в разные форматы. JSON, YAML и Excel должны возвращать байты, CSV возвращает основной DataFrame.
