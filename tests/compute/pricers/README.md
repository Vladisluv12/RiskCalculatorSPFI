# tests/compute/pricers

Тесты прайсера процентных свопов и общих утилит ценообразования.

`test_irs_pricer.py` строит мок-`DataProvider` с синтетической плоской OIS-кривой и проверяет базовые контракты прайсера: `calculate_pv` возвращает непустой `DataFrame` с дневным индексом внутри запрошенного диапазона дат, payer и receiver дают противоположные знаки NPV, квартальный график платежей не ломает расчёт. Отдельный блок проверяет EURIBOR-ветку (IBOR через flat-fixing): что NPV непуст и что ATM-своп даёт NPV, близкий к нулю.

`test_swap_utils.py` покрывает общие утилиты из `compute.pricers.swap_utils`: генерацию графика платежей с разной частотой (end-of-period, monthly, quarterly, semi-annually, annually) и гарантию, что последняя дата равна end. Проверяются day-count конвенции (ACT/360, ACT/365, 30E/360, ACT/ACT в обычный и високосный год, на стыке двух лет). Тесты OIS-дисконт-факторов проверяют монотонное убывание по тенору и корректность для плоской 10%-ной кривой. Отдельный блок проверяет правила бизнес-офсета (`OffsetRule`) включая обработку выходных. Тесты IBOR-форвардов и форвардов с базисом проверяют поведение на плоской кривой, монотонность на восходящей кривой, сдвиг при положительном базисе и корректное падение при нулевом DCF.
