# tests/compute

Группирующая директория для тестов вычислительного слоя `src/compute`. Сами тесты лежат в подпапках. В `tests/compute/pricers` собраны тесты прайсеров (IRS и общих хелперов из `swap_utils`). В `tests/compute/risk` собраны тесты метрик риска (CVaR, iVaR, модели ликвидности). См. README соответствующих подпапок и общий `tests/README.md` для команды запуска.
