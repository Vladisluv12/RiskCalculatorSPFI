# tests/utils

Тесты сервисного слоя.

`test_data_provider_fixings.py` проверяет загрузку исторических фиксингов через `utils.DataProvider.get_fixing_data`. Тесты подтверждают, что метод возвращает `DataFrame`, что индекс приведён к datetime, что фильтрация по диапазону дат работает корректно, что данные доступны для разных индексов (включая SOFR), что отсутствующий файл порождает ожидаемое исключение, и что ожидаемые CSV-файлы фиксингов действительно лежат на диске в `src/data/fixings/`.
