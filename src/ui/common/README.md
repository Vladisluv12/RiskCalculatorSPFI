# src/ui/common

Общие переиспользуемые компоненты Streamlit-интерфейса. Сюда вынесены
элементы, которые встречаются на нескольких страницах: формы добавления
инструментов в портфель, навигационная боковая панель, типовые блоки выбора
параметров VaR и блок выгрузки результатов.

## Файлы

### `sidebar.py`

Содержит функции, отрисовывающие боковую панель и формы конструирования
контрактов.

| Функция | Что делает |
|---|---|
| `render_add_instrument_form` | Универсальная форма добавления инструмента в портфель, выбирает подформу по типу инструмента. |
| `render_irs_form` | Форма параметров процентного свопа `InterestRateSwap`: валюта, плавающий индекс, частота купонов, day count, конвенции и спред. |
| `render_swap_form` | Форма валютного свопа `CurrencySwapContract`. |
| `render_forward_form` | Форма FX-форварда. |
| `render_report_sidebar` | Боковая панель с отчётом по портфелю и результатами расчётов. |
| `_get_global_valuation_date` | Возвращает единую дату оценки из `st.session_state`, чтобы все страницы работали в одной точке кривой. |

Константа `_INDEX_BY_CURRENCY` описывает соответствие валюты и доступных
плавающих индексов и используется при заполнении выпадающих списков формы
IRS.

### `components.py`

Базовые виджеты, общие для страниц риска.

| Функция | Что делает |
|---|---|
| `render_var_params` | Отрисовывает три колонки с типом VaR, доверительным уровнем, горизонтом и окном исторических данных. Возвращает выбранные значения для последующего расчёта. |
| `render_export_download` | Кнопка скачивания результатов в выбранном формате через `iolib.results_exporter`. |
| `render_report_toggle` | Переключатель отображения детального отчёта. |

## Как используется

`render_var_params` определена как переиспользуемый компонент ввода
рисковых параметров, однако в текущей версии страницы `var_page.py`,
`lvar_page.py` и `portfolio_var_page.py` дублируют ввод инлайном через
`st.columns(3)` и базовые виджеты Streamlit, а не вызывают эту функцию.
Перевод страниц на единый компонент — открытое улучшение. Страница
`portfolio_page.py` использует формы из `sidebar.py` при добавлении новых
инструментов и `render_report_sidebar` для вывода сводки по портфелю.
Виджеты не выполняют расчётов и не обращаются к `DataProvider`: они только
собирают и возвращают пользовательский ввод.
