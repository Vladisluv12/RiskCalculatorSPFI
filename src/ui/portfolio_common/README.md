# src/ui/portfolio_common

Компоненты, общие для страниц, работающих с портфелем целиком: страницы
портфеля (`portfolio_page.py`) и страницы портфельного VaR
(`portfolio_var_page.py`). Сюда вынесена отрисовка таблицы инструментов,
секция индивидуальных VaR и CVaR с агрегатами по портфелю и блок анализа P&L
с графиками.

## Файлы

### `table_view.py`

Содержит функцию `render_portfolio_table`, которая принимает портфель,
загруженный через `iolib.portfolio_io`, и отрисовывает его как `st.dataframe`
(без интерактивного выбора строк) вместе с кнопками «Очистить портфель»,
«Импорт» и «Экспорт». Логики выбора активного инструмента (`selected_id`)
внутри функции нет — `selected_id` выставляется из других мест UI.
Используется на странице работы с портфелем (`portfolio_page.py`).

### `ivar_cvar_section.py`

Содержит функцию `render_ivar_cvar_section`. Блок отображает индивидуальные
показатели VaR и CVaR по каждому инструменту портфеля и суммирующие строки.
Внутри использует ряды NPV, рассчитанные через
`compute.pricers.pricer_dispatch`, и метрики из `compute.risk.var` и
`compute.risk.civar`. Применяется на странице портфельного VaR как первый
аналитический блок до агрегации с учётом корреляций.

### `pnl_analysis.py`

Содержит функции анализа P&L портфеля.

| Функция | Что делает |
|---|---|
| `render_pnl_chart` | Строит график распределения дневных P&L портфеля и подсвечивает квантиль, соответствующий выбранному уровню значимости. |
| `render_profit_confidence_intervals` | Рассчитывает и отображает доверительные интервалы прибыли. |
| `render_pnl_analysis` | Объединяет блоки выше в единый раздел анализа P&L. |

## Как используется

На странице `portfolio_page.py` `render_portfolio_table` отвечает за
визуализацию состава портфеля и кнопки управления (очистить, импорт,
экспорт). На странице `portfolio_var_page.py` `render_portfolio_table`
не используется: страница вызывает только `render_ivar_cvar_section` для
постинструментных метрик, далее запускает агрегацию портфельного VaR из
`compute.risk.portfolio_var`, после чего `render_pnl_analysis` рисует
распределение P&L портфеля и доверительные интервалы прибыли. Все компоненты
получают рыночные данные через `utils.DataProvider`, не содержат собственной
логики ценообразования и риск-метрик и являются исключительно слоем
представления.
