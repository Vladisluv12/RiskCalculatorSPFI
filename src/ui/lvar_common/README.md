# src/ui/lvar_common

Компоненты страницы расчёта ликвидно-скорректированного VaR (`lvar_page.py`).
Здесь сосредоточены ввод параметров модели ликвидности, формирование
наблюдаемых спредов, абстракция модели ликвидности и блок отображения
результатов LVaR.

## Файлы

### `liquidity_model.py`

Описывает абстракцию модели ликвидности и её конкретные реализации, которые
используются страницей LVaR.

| Символ | Назначение |
|---|---|
| `LiquidityModelParams` | Контейнер параметров, общий для разных моделей. |
| `LiquidityModel` | Базовый интерфейс модели ликвидности. |
| `ParametricLiquidityModel` | Параметрическая модель: спред задаётся формулой по тенору и продукту. |
| `CsvLiquidityModel` | Модель, работающая со спредами, загруженными из пользовательского CSV. |
| `MODELS`, `MODELS_BY_LABEL` | Реестр доступных моделей для выпадающего списка на странице. |
| `_render_csv_preview` | Внутренняя функция предпросмотра загруженного CSV. |

Сами расчёты ликвидной добавки реализованы в `compute.modelling.liquidity`,
а компоненты этой папки лишь готовят входные данные для них.

### `lvar_inputs.py`

Формы ввода параметров модели ликвидности.

| Функция | Что делает |
|---|---|
| `render_parametric_inputs` | Рисует поля параметров параметрической модели спредов (базовый спред, наклон по тенору, мультипликаторы и так далее). |
| `render_csv_inputs` | Загрузка пользовательского CSV со спредами и предпросмотр. |
| `_render_csv_preview` | Внутренний помощник вывода первых строк загруженного файла. |

### `lvar_spreads.py`

Сборка наблюдаемых ликвидных спредов по инструментам портфеля.

| Символ | Назначение |
|---|---|
| `_TENOR_BUCKETS`, `_IRS_TENOR_BUCKETS` | Стандартные ведра по тенорам для маппинга инструментов в спреды. |
| `_PRODUCT_MAP`, `_INDEX_META` | Соответствие типа инструмента и плавающего индекса категории спреда. |
| `build_observed_spreads` | Готовит спреды для FX-инструментов. |
| `build_observed_spreads_irs` | Готовит спреды для процентных свопов. |
| `liquidity_spreads_key` | Формирует ключ для кеширования спредов между перерисовками страницы. |

### `lvar_results.py`

Блок вывода результатов и подготовки данных для модуля LVaR.

| Функция | Что делает |
|---|---|
| `build_liquidity_params` | Собирает итоговый набор параметров модели ликвидности из ввода пользователя. |
| `build_lc_dataframe` | Готовит таблицу ликвидных добавок по инструментам. |
| `render_lvar_results` | Отрисовывает таблицы и графики с результатами LVaR. |
| `render_export_section` | Кнопки выгрузки результатов LVaR в файл. |

## Поток данных страницы LVaR

Страница `lvar_page.py` сначала собирает общие параметры VaR (горизонт,
доверительный уровень, окно) инлайном (компонент `render_var_params` есть
в `common/`, но текущая версия страниц его не вызывает). Затем пользователь
выбирает модель ликвидности из `MODELS_BY_LABEL` и заполняет её параметры
вызовом полиморфного метода `model.render_inputs(supported)` — конкретная
реализация (`ParametricLiquidityModel.render_inputs` или
`CsvLiquidityModel.render_inputs`) внутри обращается к функциям
`render_parametric_inputs` или `render_csv_inputs` из `lvar_inputs.py`.

Сборка наблюдаемых спредов из портфеля (`build_observed_spreads`,
`build_observed_spreads_irs`) вызывается не самой страницей, а внутри
`lvar_results.build_liquidity_params`, куда страница передаёт уже собранные
параметры. На странице из этого слоя используется только вспомогательный
ключ `liquidity_spreads_key` для детектора устаревания результатов.

Готовые параметры передаются в `compute.risk.lvar`, который получает дневные
NPV-ряды от `compute.pricers.pricer_dispatch` через `utils.DataProvider`,
рассчитывает базовый VaR и прибавляет ликвидную надбавку, рассчитанную по
моделям из `compute.modelling.liquidity`. Результаты выводятся через
`render_lvar_results`, а выгрузка идёт через `render_export_section` и
`iolib.results_exporter`.

Замечание по техдолгу: функция `_render_csv_preview` дублируется в
`liquidity_model.py` и `lvar_inputs.py` — общая реализация ещё не выделена.
