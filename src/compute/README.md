# compute

Подпакет `compute` — вычислительное ядро проекта `course_work_risk_calc`. Здесь сосредоточена вся численная логика, которая стоит между загрузкой рыночных данных (`src/utils/DataProvider.py`) и пользовательским интерфейсом на Streamlit (`src/ui/`, `src/main.py`).

## Роль в общем потоке данных

Калькулятор риска работает по конвейеру: CSV-файлы из `src/data/` загружает `DataProvider`, далее прайсеры строят ежедневный временной ряд NPV для каждого инструмента портфеля, после чего риск-метрики (VaR, CVaR, LVaR) считаются на полученных рядах. Подпакет `compute` отвечает за два средних звена этого конвейера: оценку и расчёт риска. Кривые и модели спредов, на которые опираются прайсеры и LVaR, вынесены в отдельный слой моделирования.

## Структура подпакета

| Папка | Назначение |
|---|---|
| `pricers/` | Прайсеры по типам инструментов (IRS, FX-форварды, FX/валютные свопы) и диспетчер, направляющий контракт в нужный прайсер. Возвращают `pd.DataFrame` с дневной серией NPV. |
| `risk/` | Риск-метрики: исторический и параметрический VaR/ES, Component VaR и Incremental VaR (`civar.py`), LVaR с поправкой на ликвидность, агрегация в портфельный VaR с разложением на диверсифицированный, недиверсифицированный и некоррелированный. |
| `modelling/` | Кривые бескупонной доходности и OIS-кривые (модель Свенссона для EUR, расширенный Nelson-Siegel с гауссовыми корректорами для RUB, линейная интерполяция для USD и CNY), а также модели спредов с поправкой на ликвидность, питающие прайсеры и LVaR. |

## Контракт между слоями

Прайсеры зависят от `DataProvider` (исторические фиксинги, FX-споты, параметры кривых) и от модуля `modelling.RiskFreeRate` (OIS-дисконт-факторы, безрисковая ставка для бескупонных кривых). Риск-модули принимают на вход уже готовые серии NPV, построенные прайсерами, и при необходимости обращаются в `modelling.liquidity` за спредами для LVaR. Такое разделение позволяет менять методики оценки и риска независимо друг от друга и держать UI тонким — ему достаточно собрать портфель, выбрать диапазон дат и вызвать функции из `risk/` и `pricers/pricer_dispatch.py`.
