# compute/modelling

Пакет содержит математические модели, на которые опираются прайсеры и риск-метрики: интерполяцию кривых бескупонной доходности и OIS-кривых, а также модели стоимости ликвидации. Это нижний уровень вычислительного ядра — он не знает ничего о конкретных инструментах, но даёт прайсерам и LVaR численные характеристики рынка на нужную дату.

## RiskFreeRate.py — кривые ставок

Модуль предоставляет две точки входа: `get_risk_free_rate` для бескупонной (ZC) безрисковой ставки и `get_ois_rate` для ставки овернайт-индексных свопов. Обе функции принимают валюту и диапазон дат, читают параметры кривых из `DataProvider.get_curve_data` или `DataProvider.get_ois_curve_data` и возвращают табличные структуры: `get_risk_free_rate` отдаёт `pandas.DataFrame` с колонками `['tenor', 'rf_rate']`, `get_ois_rate` отдаёт `pandas.Series` по тенорам. Скаляр-ставку при необходимости получают, индексируя или интерполируя возвращённую таблицу.

Для евровой кривой используется параметрическая модель Свенссона (Nelson-Siegel-Svensson) с шестью параметрами `β0..β3`, `τ1`, `τ2`. Для рублёвой кривой используется расширенный Нельсон-Сигель с девятью гауссовыми корректирующими членами `G1..G9` (коэффициент масштаба `k = 1.6`). Для долларовой и юаневой кривых применяется линейная интерполяция через `scipy.interpolate.interp1d(kind='linear')` по дискретному набору спот-ставок. OIS-кривые берутся из предварительно бутстрапированных таблиц в `src/data/ois_curves/` (см. `src/utils/ois_bootstrap.py`); набор стандартных тенор-точек задан константой `_OIS_TENOR_YEARS`. На полученные ставки опираются `swap_utils.ois_discount_factor_series` и форвардные расчёты во всех прайсерах.

## liquidity.py — модели стоимости ликвидации

Модуль реализует модели спреда и стоимости ликвидации (Liquidity Cost), используемые в `compute/risk/lvar.py` для построения LVaR.

| Объект | Назначение |
|---|---|
| `LiquidityParams` | Датакласс параметров модели. Реальные поля: `k=3.0` (стресс-коэффициент для FX), `floor_spread=0.001`, `alpha=0.10`, `lambda_=0.94` (параметр EWMA), `avg_daily_volume`, `observed_spreads`, `k_irs=3.0`, `floor_spread_bps=2.0`, `observed_spreads_irs`. Уровень доверия и горизонт ликвидации передаются отдельными аргументами в `portfolio_lvar`. |
| `estimate_ewma_vol` | Оценка экспоненциально-взвешенной волатильности ряда (типично — bid-ask спреда). |
| `estimate_spread_series` | Построение серии относительного спреда из исторических цен инструмента. |
| `compute_lc` | Стоимость ликвидации не-IRS позиции. Нормальный режим: `0.5 * |mid_pv| * s_last`. Стрессовый: `0.5 * |mid_pv| * (s_last + z * σ_spread)`. Множитель — текущий `mid_pv` позиции, а не нотинал; используется последнее наблюдение спреда `s_last` плюс EWMA-волатильность для стресса. |
| `estimate_irs_spread_series` | Оценка серии спреда для процентного свопа в базисных пунктах. |
| `compute_irs_lc` | Стоимость ликвидации IRS. Сигнатура `compute_irs_lc(dv01, spread_series_bps, z_alpha)` — `LiquidityParams` напрямую не передаётся; стрессовый компонент строится как `z_alpha * σ_spread_bps` поверх последнего наблюдённого спреда. |

Разделение на два варианта `compute_lc` отражает разную природу ликвидности: для линейных FX-инструментов корректно работать с относительным bid-ask, тогда как для IRS экономически осмысленнее измерять спред в базисных пунктах ставки и переводить его в денежное выражение через DV01.
