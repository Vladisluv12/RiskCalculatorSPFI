# src/utils

Служебный слой проекта. Здесь находится единая точка доступа к рыночным данным, бутстрап OIS-кривых, валидация портфеля и набор скриптов, которые готовят демо- и тестовые данные (ликвидность, сэмпл-портфели).

## Роль в архитектуре

Прайсеры (`src/compute/pricers/`) и модели риска (`src/compute/risk/`) не работают с CSV напрямую. Все обращения к диску инкапсулированы в `DataProvider`, который выдаёт уже подготовленные `pandas.DataFrame` со срезом по нужному диапазону дат. Это позволяет одному и тому же провайдеру обслуживать оценку IRS, FX-форвардов, валютных и кросс-валютных свопов, а также LVaR-скоринг.

Скрипты-генераторы и бутстрап в этой же папке закрывают второй контур: они производят содержимое `src/data/` (OIS-кривые, файлы ликвидности, сэмпл-портфели), которое затем читает `DataProvider`.

## DataProvider.py

Класс `DataProvider` инкапсулирует доступ к CSV. Конструктор принимает один аргумент `input_dir: str = "src/data"` — корень каталога с данными. Никакого диапазона дат в конструкторе нет: окно `(first_date, last_date)` передаётся в каждый публичный метод, и каждый вызов читает соответствующий CSV напрямую через `pandas.read_csv` (внутреннего кэша нет, повторные вызовы читают файл заново).

Публичные методы:

| Метод | Что возвращает | Кому нужно |
|---|---|---|
| `get_currency_data(ticker, first_date, last_date)` | DataFrame со спот-курсом валютной пары на интервале | `ForwardPricer`, `CurrencySwapPricer` |
| `get_curve_data(currency_name, first_date, last_date)` | Параметры ZC-кривой (модель Свенссона для EUR, NS+гауссианы для RUB, точечные ставки для USD/CNY) | `IRSPricer`, FX-прайсеры |
| `get_ois_curve_data(currency, first_date, last_date)` | Бутстрапированная OIS-кривая по тенорам | `IRSPricer`, `swap_utils.ois_discount_factor_series` |
| `get_fixing_data(index, first_date, last_date)` | Историческая серия фиксингов индекса (RUONIA, ESTR, EURIBOR 3M и т.д.) | `IRSPricer` (плавающая нога) |

Имена файлов резолвятся через внутренние словари `_FIXING_FILENAMES`, `_OIS_FILENAMES`, `_CURVE_FILENAMES`, привязывающие enum-ы из `src/instruments/enums.py` (валюта, индекс) к конкретным CSV в `src/data/`.

## ois_bootstrap.py

Один раз на обновление данных строит OIS-кривые из овернайт-фиксингов и сохраняет их в `src/data/ois_curves/` (файлы `rub_ois.csv`, `eur_ois.csv`, `usd_ois.csv`, `cny_ois.csv`). После этого `DataProvider.get_ois_curve_data` отдаёт уже готовую кривую без перерасчёта.

Ключевые элементы:

`bootstrap_ois_curve(overnight_pct_series)` собирает кривую по набору тенóров `TENORS_DAYS` (от 1 дня до нескольких лет), требуя минимального покрытия окном `MIN_COVERAGE`.

`build_and_save_ois_curves(fixing_dir, output_dir)` пробегает по всем поддерживаемым валютам, читает соответствующий фиксинг (RUONIA, ESTR, SOFR, китайский овернайт) из `fixing_dir`, бутстрапит и пишет результат в `output_dir` (`src/data/ois_curves/`). Оба аргумента обязательны.

Этот модуль удобно вызывать из ноутбука или CLI после обновления данных в `src/data/fixings/`.

## validate.py

Файл зарезервирован под будущие валидаторы портфеля и в текущей версии пуст. Ни UI, ни `iolib/portfolio_io.py` его не импортируют.

## Скрипты подготовки данных

Эти модули не вызываются из рантайма прайсеров — они производят входные CSV. Запускаются как отдельные скрипты при подготовке окружения или для пересборки демо-данных.

### generate_liquidity.py

Генерирует синтетические данные ликвидности (bid-ask спреды) для FX-инструментов. Использует константы `_K`, `_FLOOR`, `_LAMBDA` (параметры модели спреда), список тикеров `_TICKERS`, продуктовых типов `_PRODUCTS` и тенóров `_TENORS`. Точка входа — `ensure_liquidity_file(...)`, которая читает мид-серию через `_load_mid_series` и формирует CSV для `src/data/liquidity/`.

### generate_irs_liquidity.py

Аналог для IRS: оценивает EWMA-волатильность ставок (`_ewma_vol_bps`) на горизонтах `TENORS_Y` и считает спред в базисных пунктах с параметрами `K_IRS`, `FLOOR_BPS`, `LAMBDA`. Источники фиксингов перечислены в `_SOURCES`. Функция `generate(...)` собирает таблицу, `main()` запускает генерацию из CLI.

### generate_sample_portfolios.py

Создаёт набор демо-портфелей `PORTFOLIOS` (RUB IRS, EUR IRS, USDRUB/EURRUB/CNYRUB/EURUSD форварды, USDRUB-своп) с предзаданными датами `TODAY`, `T2`, `END_1Y/2Y/3Y` и форвардными ставками `FWD_*`. Каждая фабрика (`rub_irs`, `eur_irs`, `usdrub_fwd`, ...) возвращает датакласс из `src/instruments/`. `main()` сериализует портфели через `iolib.portfolio_io` в выбранный формат.

### liquidity_io.py

Утилиты для чтения CSV ликвидности: `list_liquidity_files`, `liquidity_dir_path`, `load_liquidity_csv`, `load_index`, `load_for_portfolio`. `load_for_portfolio` определяет нужные тикеры через `_needed_ticker_prefixes` и подгружает только релевантные файлы — используется при расчёте LVaR, чтобы не читать весь каталог.

### split_liquidity.py

Разбивает крупный CSV ликвидности на батчи (`_batch_name`, `split`) — нужно, чтобы хранить демо-данные в репозитории по частям, не упираясь в лимит размера файла.

### bootstrap_test_data.py

Функция `bootstrap_test_data()` — оркестратор для тестов: подготавливает минимально достаточное состояние `src/data/` (OIS-кривые, ликвидность, сэмплы), чтобы pytest мог гонять прайсеры и риск-модели на воспроизводимом наборе.
