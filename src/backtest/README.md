# src/backtest

Заглушка под будущий модуль бэктестинга рисковых метрик. На текущий момент пакет содержит только `__init__.py` и не предоставляет публичного API.

Предполагаемая роль: воспроизводить расчёт VaR, LVaR и CVaR на скользящем окне исторических данных и сопоставлять прогноз с фактическими P&L (backtesting по методу Купьека, Christoffersen и т.п.) для оценки качества моделей.
